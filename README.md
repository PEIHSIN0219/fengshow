# 豐說享秀官網 V3｜提案展示版

這是可直接放在 GitHub Pages 的靜態多頁網站。所有選單、年度頁面、官方社群連結均可點選。

## 上線方式
1. 解壓縮 zip。
2. 將資料夾 **內部所有檔案與資料夾** 上傳至 GitHub repo 根目錄（不要多包一層 `fengshow-v3`）。
3. GitHub → Settings → Pages → Deploy from a branch → main / (root)。
4. 首頁為 `index.html`。

## 修改方式
- 全站外觀：`styles.css`
- 手機選單：`script.js`
- 各頁文字：對應 `.html` 檔案
- 歷屆頁：`archive/2022.html` 至 `archive/2026.html`
- 家庭日：`family/2025.html`、`family/2026.html`
